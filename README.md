## Case Studies

### Case Study 01: Personal Portfolio Website

Created a personal portfolio website to display personal information, educational qualifications, technical skills, hobbies, and projects.

**HTML concepts used:** Headings, paragraphs, `div`, `section`, tables, lists, links, and favicon.

**CSS properties used:** `background-color`, `color`, `font-family`, `text-align`, `padding`, and `margin`.

### Case Study 02: College Information and Admission Website

Developed a college website to present college information, courses, facilities, admission details, and contact information. The page includes a navigation section and an Apply Now button.

**HTML concepts used:** Headings, paragraphs, `div`, `section`, navigation links, lists, buttons, footer, and favicon.

**CSS properties used:** `background-color`, `color`, `text-align`, `font-size`, `padding`, `margin`, `text-decoration`, and `border-radius`.

### Case Study 16: Travel Agency Website

Created a travel agency website to display popular tourist destinations, travel packages, prices, destination images, and a travel inquiry form.

**HTML concepts used:** Headings, paragraphs, `div`, `section`, navigation links, images, tables, forms, labels, input fields, dropdown options, buttons, footer, and favicon.

**CSS properties used:** `background-color`, `color`, `text-align`, `padding`, `margin`, `border-radius`, `width`, and `height`.

## Technologies Used

- **CSS** – To style webpages and improve their appearance.
